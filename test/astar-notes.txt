Heuristic search

A* search is a best-first search algorithm. It picks the node with the lowest value of f(n) = g(n) + h(n), where g(n) is the cost so far from the start and h(n) is the heuristic estimate of the cost to the goal.

A heuristic is admissible if it never overestimates the true cost to reach the goal. If the heuristic is admissible, A* is guaranteed to find an optimal (cheapest) path.

Manhattan distance is a common admissible heuristic on a grid where you can only move up, down, left and right. It adds the horizontal and vertical distances.

Greedy best-first search uses only h(n). It is often fast but it is not guaranteed to find the best path.
